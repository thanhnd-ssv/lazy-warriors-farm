# Web Workflow Utility

## Cài đặt

Cài Tampermonkey, sau đó chọn đúng phiên bản:

- **Thành viên:** [Cài bản giới hạn Ruộng/Chuồng](https://raw.githubusercontent.com/thanhnd-ssv/lazy-warriors-farm/refs/heads/main/script.user.js)
- **Admin:** [Cài bản đầy đủ](https://raw.githubusercontent.com/thanhnd-ssv/lazy-warriors-farm/refs/heads/main/script.admin.user.js)

Mở trang game, bấm biểu tượng ngôi sao để mở bảng điều khiển, rồi bật tự động trong mục **Chung**. Chỉ cài một phiên bản.

## Cập nhật

Tampermonkey tự kiểm tra phiên bản mới. Có thể kiểm tra thủ công trong **Dashboard → Utilities → Check for userscript updates**. Tải lại trang game sau khi cập nhật.

Admin phát hành bản mới bằng cách tăng `@version` và push script cùng metadata tương ứng lên GitHub.
